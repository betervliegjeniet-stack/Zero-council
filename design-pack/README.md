Design reference (read-only). `data/cards.json` overrides any rules text found here.

- `Zero_Hour_Card_Game_Design_Pack.pdf`: the "Zero Hour" art bible (layout grid, palette, 16 prototype cards).
- `plates/plate-000..003.png`: the four card spreads extracted from that PDF (4 cards each), used as the
  source for card art crops in M4.

The full `Zero_Council_Master_Design_Pack` (GDD, CSV, rulebooks, individual card PNGs) is not in the repo.
